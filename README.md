# Digital Systems: UART Receiver in VHDL (INC)

## Overview
Hardware design of a Universal Asynchronous Receiver-Transmitter (UART) controller. Includes a structural VHDL implementation of the receiving side (RX) with a Finite State Machine (FSM) for timing and data validation.

## Key Features
- **FSM Design:** State machine for detecting start bits, data bits, and stop bits.
- **Hardware Abstraction:** VHDL implementation ready for FPGA deployment.
- **Validation:** Includes logic for data valid (`DOUT_VLD`) signaling.
